# 知学 · B1 双向学业支持演示

建议时长 8–10 分钟。按 README 启动当前独立项目，先使用学生演示账户 `2024CS013`，之后使用该学生的辅导员 `C01`，最后切换 `admin` 核验。软件专业可用 `2024SE014` 验证未明说专业时仍正确查询170学分要求。演示环境密码均为 `demo123`，全部个人信息与处置记录均为模拟。

## 0:00–0:40：从学生遇到的问题进入

“我们选择 B1 学业预警与学情画像。学生需要知道风险来自哪里、现在可以做什么，辅导员需要把成绩、学分和选课信息放在一起判断，并持续跟踪帮助是否落实。知学让学生与老师围绕同一份证据沟通，服务‘智汇郑大，共创未来’的校园应用主题。”

以学生 `2024CS013` 登录，说明当前只显示本人的学情。先展示模拟标识，避免把模拟数据说成学校正式成绩。

## 0:40–2:10：学生理解原因与培养方案

打开学情详情，展示成绩趋势、未通过课程、学分进度与选课情况。展开一条预警，说明“哪项记录、什么条件、需要核实什么”。

打开学分核算与原培养方案：计科总要求 173 学分，软件总要求 170 学分；查看通识、专业、个性化三类缺口。该学生为大三，展示已经到计划学期但未完成的必修课和后续学期负荷。

说明未出成绩不会当作零分，未来课程不会因当前未选就算漏选，同课重修通过只计一次学分。培养方案提供计划要求，年度开课、适用届别和替代认定仍需教务确认。

## 2:10–4:20：学生连续咨询并采纳行动

向助手提问：“为什么出现这条预警？请按证据列出本周需要核实的事项。”展示工具执行步骤、资料依据与建议。

继续追问：“那给我一份本周能执行的学习行动计划。”展示延续同一学生的对话、实际工具步骤、来源与可检查草案。先说明尚未写入任务，再点击“采纳这份计划”，到行动清单查看新增任务；刷新对话，已采纳状态应保留，不能重复创建。

按实际模式介绍：本地模式运行多步学情工作流；远程模式将工具结果返回模型，允许继续查询再回答。没有真实密钥时不要把本地结果说成某大模型生成。自然语言数字与引用核验是保护措施，不是绝无幻觉的证明；工具不能直接改成绩或结案。

学生建立一条行动计划，例如“周四参加数据结构答疑”，填写截止日期；将已完成的行动标记完成。再向本人的预警提交进展：“演示：已复习第一章，准备周四答疑，想进一步确认补修安排。”保存后重新读取，证明记录已经持久化。

强调学生可以主动反馈和安排自己的学习，不只接收预警；学生反馈不会直接改变老师的处置状态。

## 4:20–5:50：学生规划课程并提交

在“学分核对”确认外语路线、个性化路径及进阶模块，查看限选课、任选最低学分和共享课程分配。未知交叉/自选认定会明确标为待核实，不假装完成毕业审核。

打开“学期选课规划”，选择当前或下学期，采用推荐组合再手动调整。演示一次先修或时段冲突，并展示课程来源；核验后保存标题与选择理由，再提交给辅导员。提醒这是规划，不是向教务系统选课。建议用准备好的模拟开课安排稳定演示，不能把模拟时段称为真实课表。

## 5:50–7:40：辅导员收到进展并跟进

退出学生账户，使用 `C01` 登录。打开站内通知，找到刚才的学习进展，再进入同一学生的详情和行动计划。

先在“学生选课方案”查看学生刚提交的组合、理由及检查结果，填写“认可”或“建议调整”的具体意见。回到学生端应能看到意见和事件时间线。再次调整偏好会使旧方案需要复核，不沿用过期批准结论。

再展示老师负责范围内的风险与待办，读取学生反馈，按当前允许的步骤进行联系、帮扶、复查和结案。建议说明：“演示：已核对补修需求，安排每周一次答疑，下周复查。”填写措施和复查日期，并查看时间线与操作者。也可给学生安排一项行动，学生完成后老师收到通知。

选择一条“待联系”预警可以完整走完联系→帮扶→复查→结案；若当前这条已有演示跟进记录，则从当前状态继续。结案须有说明，不能跳过流程。结案与原始风险是否消除分别记录。

最后导出当前辅导员范围的台账 CSV。自动分发指站内通知，不能声称已经联系真实辅导员或发出真实短信。

## 7:40–9:00：管理员核验数据与结果

使用 `admin` 登录，展示模拟学生总数 144、数据导入模板和规则说明。可用一条模板记录演示更新，错误输入应有具体行号反馈；不覆盖真实学生材料。

展示原128例回归和 `docs/support-validation.json` 中20种不同设计、两专业共40例的异质验收，说明具体覆盖了哪些规则。整体功能测试数量以 `docs/验收记录.md` 的最新记录为准，代码改变后需重跑相关项。

建议表述：“合成场景用于核对实现与预期是否一致，不是真实校园预测准确率。官方 B1 没有写数字达标线；真实应用需要独立标注和按学生或时间划分的数据，再评价误报、漏报。”

## 可准备的答辩说明

- **如何符合 B1？** 依次展示数据融合、学生多维画像、三级预警、自动归属与通知、处置闭环、培养方案核算及大三提前提醒。
- **学生能做什么？** 查看本人风险证据和学分缺口，询问助手，建立行动计划，反馈学习进展；老师能在同一流程内看到并回应。
- **智能体起什么作用？** 延续学生、专业、课程和学期上下文，连续查询学情、方案、开课和冲突，再给出有依据的解释或可采纳草案。写入任务需用户点击采纳，正式帮扶决定由辅导员执行。
- **如何落地？** 与需求部门核实规则、届别和数据权限，再对接教务与消息渠道，以获授权的小规模真实场景验证作为下一步。
