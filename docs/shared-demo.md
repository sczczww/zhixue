# 知学共享体验部署

## 共享体验模式

共享体验使用模拟记录，开放学生和辅导员账号。管理员登录、管理接口和门户换票关闭，助手使用本地学情工作流。

在本机运行共享体验可执行 `python run.py --public-demo --no-browser --port 18777`。默认数据库保存在 `var/shared-demo.sqlite3`，服务器监听本机。生成外部访问地址需要另行部署或配置转发服务。

## Railway 配置

项目已提供 Dockerfile。2026年11月13日已在 Railway 完成云端构建。平台当前的新服务使用控制台服务设置，本项目的启动检查、重试和休眠参数在控制台配置。

当前可访问[知学独立版](https://zhixue-production-4c203c74.up.railway.app/)和[校园版](https://zhixue-production-4c203c74.up.railway.app/campus)。

1. 登录 Railway，确认账号实际可用的试用额度和资格。
2. 上传本次交付的源码，或使用已同步到该版本的代码仓库。将含 Dockerfile、server、web、data 的 `zhixue` 目录设置为服务根目录。
3. 给该服务添加持久磁盘，挂载路径填写 `/data`。创建后再启动正式试用，运行实例保持一个。
4. Dockerfile 已将 `ZHIXUE_DB` 配置为 `/data/shared-demo.sqlite3`，并启用共享模拟模式。平台分配的 `PORT` 会用于启动服务。
5. 设置健康检查为 `/api/status`，等待时间120秒，失败最多重试3次，开启 Serverless 空闲休眠。检查 `/api/status` 返回 `publicDemo: true`、`demo: true` 以及助手 `mode: local`，再生成平台提供的 HTTPS 地址。
6. 用电脑和手机分别测试登录、选课比较、提交方案和辅导员反馈。重启一次服务，确认刚保存的记录仍能读取。

网址根路径是知学独立版，`/campus` 是校园版。试用者可以使用不同模拟学生账号。辅导员只能处理系统分配给自己的学生。

试用额度有金额和时间限制，应查看控制台的实际剩余额度。费用计划、额外资源和继续付费由项目负责人决定。
