# Independent academic workspace

Operate on the existing green product. Students and counselors have the same core services as the campus entrance and the same scoped records. Only the independent entrance uses this layout.

Homepage-only preview exception (2026-11-14): the student's `mine` page and active `.independent.home-preview` shell follow `web-student-home-js.md`. Its white rail, cool canvas, fine borders and sans-serif type retain the user-selected Attio + Udacity direction and the existing green primary. The B1 refinement now leads with warning evidence, conditional next-term risk, counselor follow-up and personal actions before the wider academic portrait. Compact course records replace the earlier decorative covers; their source image files remain as prior-preview records, and the current homepage uses none. The direction below remains the incumbent contract for login, counselor and all other independent pages. This local preview is neither acceptance of a whole-application redesign nor a production deployment.

## Direction contract

- One real next step comes first. For a student, lead with the highest active warning, an outstanding task, or a planning step according to their data. A counselor starts with the server's priority follow-up and reaches the record directly.
- Use a light sage navigation rail, warm paper workspace, restrained evergreen action panel, large Chinese serif titles, readable sans-serif controls, and true credit figures. The only photograph belongs to sign-in.
- For independent study, credit detail, evidence, conversations and course decisions are available on demand. Split selection from checking and submitting; keep selections and typed notes across tab changes. Keep grade policy, attribution and simulation labels available.
- Store server-calculated comparison evidence with saved course plans. Show the adopted alternative, calculation date and assumptions; mark changes to the course set or degree path. Counselor tabs keep written feedback intact while switching among rationale, course checks and history.
- On mobile, controls remain labeled, the menu opens and closes by keyboard, extra table columns become records or contained scrolling, and charts fit the reading column. The main application must never overflow horizontally.
- Visual evidence and role checks in ../inspection/2026-11-07/independent-front (relative to the project). The public source and archive exclude local databases, user secrets and QA records.
- Login photo: generated for this local interface on 2026-11-07. A forest-green book and open notebook on a sunlit library table. The compressed local WebP does not require a network request to any external service.
